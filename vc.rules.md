Rules VibeRails enforces on every commit. Each rule is a list item under the rules heading
below; the optional Files section lists files covered by this policy.

Terminal changes require Rob's signed approval of the staged tree. Shared launch, host,
and UI files are included because changes there can alter terminal behavior. See the
[terminal review checklist](docs/terminal-change-review.md) for scope and review priorities.
