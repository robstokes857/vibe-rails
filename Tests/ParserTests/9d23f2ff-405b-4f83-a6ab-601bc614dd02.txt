Why this works

- _transitionTo(THINKING) automatically sets _awaitingFirstIdle = true
- Existing onSessionIdle() checks _awaitingFirstIdle and transitions to READY
- After READY, normal Enter → THINKING → idle → READY cycle continues unchanged
- Flag is consumed (reset to false) on socket open, so reconnects behave normally
- Normal sessions never set the flag, so their flow is unchanged

rogress bar), then "Ready" on first
3. After "Ready" in a resumed session, press Enter — should cycle to "Thinking" then "Ready" as normal
